ADDED SESSION PROTOCOL

Evidence must stay attached and current

The supervisor reruns after watched edits, treats missing instrumentation as incomplete, and gives the synchronous agent hook a decision for the current revision.

Could hooks around pytest achieve similar control?Yes. A controller that runs the right tests after every relevant edit, detects missing or stale execution, preserves repair access, and blocks the agent on failure can provide similar protection. Melampus packages that loop around contracts attached to generated units; it complements the broader regression suite.
06 / TRY IT

Run the same example yourself.

Python 3.11+ and uv on macOS or Linux. The recorder creates a disposable copy; it does not change the repository’s example.

  1. Get the demo implementation

    This recording uses the first-release branch in PR #6. Publication on PyPI is not required.

    git clone --branch feat/first-release https://github.com/melampus-org/melampus-python.git
cd melampus-python
uv sync --locked --all-extras

  2. Try the protocol without a model request

    This version seeds and repairs the defect with a script. It exercises the real supervisor and gate, but is not an AI repair demonstration.

    uv run --locked python scripts/record_agent_demo.py --output demo-recordings/protocol

  3. Compare unit tests and the agent gate

    This makes two temporary edits, runs the smoke and boundary tests, queries a live Melampus session, then restores the source.

    uv run --locked python examples/agent-session/compare_with_unit_tests.py

  4. Record a real Claude Code repair

    Install and sign in to Claude Code first. This makes a request with your own account and configured model. Use a new output directory for each run.

    uv run --locked python scripts/record_agent_demo.py --live-claude --output demo-recordings/live

    Review run.json, the sanitized agent transcript, hook decisions, and source snapshots. Model behavior and timing can differ from this recording.

  5. Keep Melampus beside your own coding session

    Open two terminals at the repository root. Review the sample’s contract, scenario, configuration and Claude hooks before enabling them.

    TERMINAL A · SUPERVISOR
    source .venv/bin/activate
cd examples/agent-session
melampus session
    TERMINAL B · YOUR AGENT
    source .venv/bin/activate
cd examples/agent-session
melampus gate
claude

    Ask Claude to modify pricing:price while preserving PRICE.instrument and the reviewed intent. If intent needs to change, have the owner review it and restart the session. See the agent-session guide for configuration and adapters.

07 / VALUE

Keep human review focused on intent.

The loop handles repeated feedback

  • Re-executes the configured scenario when watched code changes.
  • Returns specific failed claims to the coding agent.
  • Blocks unrelated progression while allowing scoped repair.
  • Keeps reviewed assertions separate from implementation edits.

The team still owns the specification

  • Choose valuable predicates and representative scenarios.
  • Check coverage of the paths that matter.
  • Review meaningful behavior changes, including repair choices.
  • Keep unit tests, CI, security checks and code review.

Tests with the same inputs and assertions can catch this same bug. Melampus adds the continuously running session loop, evidence freshness and agent action gating. It does not infer all business intent from prose or guarantee that generated code is correct.
