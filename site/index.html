WHAT CHANGES

The oracle is familiar. The control point is different.

Keep pytest and CI. Melampus packages them into a local protocol the coding agent cannot silently step around.

CapabilityUnit tests / CIMelampus session
Assert expected behaviorYesYes — reuses executable checks
Run immediately after watched editsOnly with a watcher or agent disciplineBuilt into the supervisor
Prove evidence belongs to this revisionUsually a CI commit or test invocationRevision-bound session evidence
Distinguish failed from missing evidenceRequires custom orchestrationHealthy, drift, and incomplete states
Block the agent's next unrelated actionUsually after push or on requestSynchronous coding-agent gate
A controller around pytest can provide similar protection. Melampus is useful when you want that controller, evidence model, and agent gate as one reviewed protocol.
